# Bruitages

Pose tes fichiers **directement ici** (pas de sous-dossier). Le nom doit
commencer par le mot-clé, l'extension est libre :

| Mot-clé   | Bouton        | Exemples de noms acceptés              |
|-----------|---------------|----------------------------------------|
| `violon`  | A (maintenu)  | `violon.mp3`, `violon_boucle.ogg`      |
| `binks`   | 1             | `binks.mp3`, `binks_rythme.wav`        |
| `yohoho`  | B             | `yohoho.mp3`, `yohoho_rire.ogg`        |

Formats conseillés : **.ogg** ou **.wav** (le .mp3 passe aussi, le .m4a non).

Le violon doit être un court extrait **sans silence au début ni à la fin**,
prévu pour tourner en boucle tant que tu maintiens A.

Vérifie ce que le programme a trouvé avec :

```bash
python3 brook.py --list
```
