# Chansons

Pose tes chansons **directement ici**. Elles sont jouées dans l'ordre
alphabétique.

- Bouton **2** : chanson suivante
- Croix **bas** : chanson précédente
- Bouton **Home** : on coupe tout

Formats : `.mp3`, `.wav`, `.ogg`, `.flac`, `.opus`
(`.m4a` / `.aac` → convertis en `.ogg`).

Astuce : renomme tes fichiers avec un préfixe numérique pour choisir l'ordre,
par exemple `01-binks-no-sake.ogg`, `02-yohoho.ogg`.
